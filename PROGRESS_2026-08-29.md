### Vulnerability detection fix

- Reworked `vulnerability_detection.py` to avoid depending only on a direct Syft scan of the extracted package.
- Current detection order is:
  1. direct `Syft -> Grype` on the extracted package
  2. generated npm lockfile project -> `Syft -> Grype`
  3. `npm audit` only as a final fallback
- This keeps the detection path closer to the original proposal while still handling npm package-version inputs reliably.
